# 文件树与 Toast 视觉调整

2026-11-17。使用 frontend-design 与 shadcn skill，复用项目 Base UI 组件。

## 设计与改动

- 沿用现有 Geist 字体和中性色 token。深色参考为背景 #0a0a0a、浮层 #171717、选中背景 #262626、正文 #fafafa、次要文字 #a1a1a1；不新增主题颜色。
- 文件树的名称区与操作按钮仍为相邻独立控件；将名称按钮的键盘焦点框移至整行，悬停、选中和菜单打开时保持整行背景连贯。
- 空目录展开不渲染占位文字或额外空行。
- Toast 最大宽度从 384px 调整为 320px，缩小圆角和内边距；图标与标题顶端对齐，标题 13px、路径 12px，关闭按钮更紧凑。长文本允许完整换行，无 action 时不渲染 action 控件。保留 3 秒成功提示和 5 秒错误提示，并支持减少动态效果偏好。
