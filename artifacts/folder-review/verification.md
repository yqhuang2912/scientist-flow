## 限制

删除不支持撤销、回收站或事务回滚。逐层路径检查和提交前复查可拒绝已有链接，但 Node 路径式文件系统 API 不提供跨进程原子路径锁，不能承诺抵御外部进程在校验与系统调用之间恶意替换目录。写操作串行控制作用于当前服务进程。

所有删除测试只使用本轮创建的临时目录或验收目录。未改数据库结构、依赖、聊天链路、绑定或根目录迁移；未提交、推送或部署。
